# Notebook

Handwritten pages kept on iPhone or iPad and shared to the library as a PDF attachment.

## Information kept

- **Title** — The notebook name.
- **Pages** — Ink and page backgrounds, including imported PDF pages.
- **Destination** — The class and optional lecture.
- **Changed** — When the notebook was last edited.
- **Saved copy** — The last attachment and when it was sent.
