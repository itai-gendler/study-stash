# Notes draft

A proposed replacement write-up, distinct from the lecture’s current notes and presented for the student to choose.

## Information kept

- **Text** — The proposed replacement notes.
- **Writer** — The selected rewriting engine.
- **Created** — When the draft became ready.
- **Source attachments** — Which attached files contributed to this rewrite.

## States

### Proposed

Ready for comparison with the existing notes.

### Accepted

Chosen as the current notes; the proposal is cleared.

### Dismissed

The existing notes were kept; the proposal is cleared.
